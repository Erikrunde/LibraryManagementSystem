Instructions for how to run the program:
You just need regular JavaFX and jdk, sdk whatever.

If you happen to have a file called books.txt, rename it please.

Launch the program out of HelloApplication.java.
To add a book, navigate to the showAdd interface by clicking the button to add a book in the main menu.

Type in the name of a book you want to add, call it whatever you want and click Confirm.

Navigate to the main menu using the Back button on the bottom of the pane.

Whenever you want to see the list of books again, click Show List on the main menu. This method is also called whenever any changes are made.

To delete a book, click Delete book on the main menu, and type in the Book Number of the book you want to delete. To get the book number, you can find it in the Show List.

To search for a book, and possibly borrow it, click Search for a book, type in the exact name, and then click Confirm. A list of books will slide in and you can borrow any of them by clicking the Borrow button, as long as they are not currently being borrowed.

To return a book, click Return book in the main menu and type in the Book Number being returned, then hit Confirm. The return date will be registered, and the status set to Available.

That's it, enjoy!
